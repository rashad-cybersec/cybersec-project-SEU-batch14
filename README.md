## 📬 How to Submit Your Work
Follow these 3 steps carefully.

---

### Step 1 — Create your own GitHub repository

1. Go to [https://github.com](https://github.com) and create a free account if you don't have one
2. Click the **+** icon (top right) → **New repository**
3. Name it exactly like this (student name):

4. **Example:** 'cybersec-project-SEU-batch14-yourname`
4. Set visibility to **Public**
5. Check **"Add a README file"**
6. Click **Create repository**

### Step 2 — Upload your work

Your submission must include:

| File | Description |
|------|-------------|
| `CyberSec_VA_PT_Assessment_v2.docx` | Your completed answer sheet |
| `screenshots/` | A folder containing all required screenshots |

**To upload:**
1. Inside your repo, click **Add file → Upload files**
2. Upload your completed answer sheet and all screenshots
3. For screenshots, create a folder named `screenshots` and upload all images inside it
4. Write this as your commit message:
5. **Example:** `Final submission - Rahman Khan - 12345`
5. Click **Commit changes**

---

### Step 3 — Submit your repo link

Once uploaded, copy your repository URL. It will look like this:
https://github.com/yourusername/cybersec-project-SEU-batch14-yourname
Mail this link to **[engr.rashadul@gmail.com]** before the deadline.
